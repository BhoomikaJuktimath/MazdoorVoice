# LinkedIn Draft

I built **MazdoorVoice — Every Worker Deserves a Record** for the Great Indian AI Internship Challenge.

Millions of informal workers deserve an easy way to remember the work days, wage agreements, advances and payments they have confirmed. MazdoorVoice is a voice-first wage record MVP: workers can speak in a supported Indian language, review the transcript and details, then track the calculated balance from their own records.

The application integrates Gnani AI **Prisma v3.0** for speech-to-text and **Timbre v2.5** for spoken summaries when an API key is configured. The worker stays in control: the transcript and extracted fields are reviewable, and a record is saved only after confirmation. Demo mode is clearly labelled and does not fake API responses.

Prisma and Timbre calls are implemented against the official API docs; I have not verified live calls because an API key was unavailable during this build.
